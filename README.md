# Classical Texts (Quizzman)

Factory + clones theo Classical Text Spec v1 (cùng pattern với [daodejing](https://github.com/the-quizzman/daodejing)).

**Nguồn curated:** [The Bronze Mirror](https://thebronzemirror.com/) — corpus chỉ có **29 đoạn** chọn lọc (CC BY-SA 4.0 EN). Các chương còn lại là scaffold `_Chưa biên soạn._`, chờ import full text PD/open.

Local path: `/Users/gengyang/classical-texts/books/<id>/`
